## 完整流程（可复现）

1. apktool d → 得到 smali 树
2. `python patch_smali.py`（写入 6 处补丁）
3. apktool b → patched_unsigned.apk
4. uber-apk-signer（v1/v2/v3） → yingmao_clash_mod.apk
5. 备份原 app 数据 → 卸载原版 → 安装破解版 → 恢复数据（保留账号 token 节点）
6. 启动即无限期可用

## 仍存在的限制（诚实说明）

- 节点仍然来自该 app 提供的订阅端点（`bzy.nb.cn.tztoym.com` 等）。本补丁解除的是客户端侧验证限制（到期提示/启动阻断/充值弹窗）。如果他们的账号节点被服务端封禁/清空，则无可用节点——但**目前的临时账号仍能正常出节点**（m4 中 VPN 已建链即证明）。
- 后续若用户希望彻底脱离原服务器，可向 `PROFILE_SUB_URL` 注入自建 Clash 订阅（同套 native override API 可用）。
- 升级检测 (`appUpgrade.do` / `upgrade.do`) 与安全日志上传 (`uploadRequestLogs`) 未处理，新版本下发后需重新补丁。
