# 诊断报告：为什么"显示过期 / 连不上外网"（2026-10-15）

## 一、结论（一句话）

**破解没失效，是鹰猫服务端把这个设备/账号停用了。** 客户端补丁能解除本地限制，但**造不出节点**——
服务端一停，41 个节点就全部作废。你看到的"账户已过期"弹窗是服务端判定驱动的。

## 二、弹窗定位

点"启动"时弹出的 **「温馨提示：您的账户已经过期，请续费后继续体验畅快感受…[离开][续费]」**：

| 项 | 位置 |
|---|---|
| 布局 | `res/layout/exitend_dialog_view_layout.xml`（id `0x7f0d0058`） |
| 按钮 | `@id/tvLeave`（离开）、`@id/tvRenewal`（续费） |
| 触发代码 | `com.yingmao.clash.act.UIMainActivity.smali:2926`（`httpSuccess` 内，按服务端响应分支） |
| 正文文案 | 不在 strings.xml —— **文字烧在图片 `@mipmap/lean_bg` 里**（所以搜不到） |

注：首页/设置页的"到期时间"显示的是我们补丁后的 **2098年12月25日**（`g()` 补丁有效），
但这个弹窗走的是**服务端响应分支**，本地补丁盖不住。

| 测试 | 结果 |
|---|---|
